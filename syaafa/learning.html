My Lifelong Learning Journey

Through independent learning, I discovered how Data Analytics transforms raw data into useful information. I also learned that continuous learning is important because technology and workplace skills are constantly developing.

What I Learned

I learned about data collection, cleaning, analysis and visualisation. I also discovered how organisations use data to identify patterns and make better decisions.

New Knowledge and Skills

  • Understanding the Data Analytics process.
  • Identifying patterns and trends in data.
  • Understanding charts and dashboards.
  • Recognising the importance of data privacy.

Why Data Analytics is Important

Data Analytics is important because organisations use data to support decisions and improve performance. These skills are useful in many areas such as business, education and healthcare.

My Future Learning Plan

I would like to improve my practical skills in Excel, SQL, Power BI and Python. I plan to continue learning through online courses, tutorials and small projects using real datasets.

Learning Resources

1. Microsoft Learn

Provides learning materials for Data Analytics and Power BI. It can help me develop practical data visualisation skills.

2. IBM SkillsBuild

Provides learning resources for data analysis and digital skills. It can strengthen my understanding of Data Analytics.

3. Kaggle Learn

Provides practical courses and datasets. It can help me practise Python and analyse real data.

4. Google Data Analytics Certificate

Provides structured training in data analysis, spreadsheets, SQL and visualisation. It can help develop career-related skills.

5. Microsoft Power BI Learning

Teaches how to analyse and visualise data using Power BI. It can help me learn how to create reports and dashboards.

Personal Reflection

Learning about Data Analytics has helped me understand that data is more than numbers. It can provide useful information for solving problems and making decisions. I would like to continue improving my Data Analytics skills for my future studies and career.
